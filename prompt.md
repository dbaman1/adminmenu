# AdminMenu

## Description
Attached is menu.sh, which is a sysadmin utility menu shell for viewing/discovering various bits of
info/configuration in a unix server, without the need to memorize arcane commands -- instead menu.sh
can be utilized.  

## Details
The menu.sh script uses a crude terminal menuing system that can be used to move amongst the menu.  It also uses
colors to enhance the terminal interface.  

Examples of the data/diagnostics/information that are available to display/browse include:

1. IP Address(es)
1. System Architecture
1. CPU  
1. PCI Bus 
1. Block Devices 
1. USB 
1. Memory 
1. Linux Distribution
1. OS Details

The intent is that this script will be installed on all servers and used for quick viewing of system 
information.
